# ☁️ AWS Solution Architect Study Notes

This folder contains a structured AWS learning path for Solution Architect preparation, written in a format similar to the Kubernetes notes in this repository.

## 📚 Study Flow

- 01-AWS-Introduction: AWS basics, global infrastructure, and core service categories
- 02-Compute & Networking: EC2, VPC, subnets, routing, and connectivity
- 03-Storage & Databases: S3, EBS, RDS, and DynamoDB
- 04-Security & Identity: IAM, KMS, encryption, and access control
- 05-Architecture & Resilience: HA, DR, load balancing, and auto scaling
- 06-Containers & Automation: ECS, EKS, Lambda, CloudFormation, and Terraform
- 07-Observability & Costing: CloudWatch, CloudTrail, monitoring, and cost optimization
- 08-Advanced AWS Services: Route 53, CloudFront, Elastic Beanstalk, and serverless services
- 10-Exam Prep & Misc: interview questions and revision notes

## 🎯 Goal

These notes are meant to help you understand AWS services, compare them properly, and prepare for interviews and architect-level discussions.
