# ☁️ AWS Solution Architect Study Notes

This folder contains a structured AWS learning path for Solution Architect preparation. The notes are now written in a more practical format with deeper explanations, architecture diagrams, and hands-on lab guidance.

## 📚 Study Flow

- 01-AWS-Introduction: AWS basics, global infrastructure, and core service categories
- 02-Compute & Networking: EC2, VPC, subnets, routing, and connectivity
- 03-Storage & Databases: S3, EBS, RDS, and DynamoDB
- 04-Security & Identity: IAM, KMS, encryption, and access control
- 05-Architecture & Resilience: HA, DR, load balancing, and auto scaling
- 06-Containers & Automation: ECS, EKS, Lambda, CloudFormation, and Terraform
- 07-Observability & Costing: CloudWatch, CloudTrail, monitoring, and cost optimization
- 08-Advanced AWS Services: Route 53, CloudFront, Elastic Beanstalk, and serverless services
- 10-Exam Prep & Misc: interview questions and revision notes

## 🎯 Goal

These notes are meant to help you understand AWS services, compare them properly, and prepare for interviews and architect-level discussions.

## ✨ What was improved
- detailed theory instead of short notes
- icon-based headings for easier reading
- Mermaid diagrams to explain architecture patterns
- practical sections with manual lab steps
- Terraform examples for provisioning core resources
- teaching-friendly instructions that walk students through each action clearly

## 🧭 Recommended Learning Order
1. Start with AWS introduction and core concepts
2. Move into compute, networking, and storage
3. Learn security and identity controls
4. Study architecture patterns and resilience
5. Practice with Terraform and real-world lab scenarios

## 📚 Expanded Topic Coverage
The notes now also include guidance for commonly taught services such as:
- SNS, SQS, and EventBridge
- WAF and Shield
- CloudWatch alarms, logs, and dashboards
- IAM, KMS, and access control
- VPC networking, route tables, and NAT
- EC2, S3, RDS, and DynamoDB

## 🧑‍🏫 Teaching Playbook
For teaching these topics effectively, use this simple pattern for each service:
1. Explain the concept in simple language.
2. Show the architecture diagram.
3. Walk through the manual lab step by step.
4. Reinforce the point with a real-world example.
5. Show a Terraform example for automation.
6. Finish with interview-style questions and common mistakes.

A ready reference for this pattern is available in [AWS/10-Exam Prep & Misc/02-Teaching-Playbook.md](AWS/10-Exam%20Prep%20&%20Misc/02-Teaching-Playbook.md).
