# 🌍 Route 53 and CloudFront

## Amazon Route 53
Route 53 is AWS’s DNS and domain management service. It can route traffic to AWS resources or external endpoints.

## Routing Policies
- Simple routing
- Weighted routing
- Latency-based routing
- Failover routing
- Geolocation routing

## Amazon CloudFront
CloudFront is a CDN that delivers content with low latency by caching it at edge locations.

## Common Use Cases
- Static website delivery
- Media streaming
- API acceleration

## Exam Notes
- Route 53 is used for DNS and traffic routing.
- CloudFront improves performance by caching content close to users.
